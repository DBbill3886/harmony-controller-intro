# HarmonyController 介绍影片旁白文案（初版）

第一人称口语，指定 MOSS 音色朗读。在价格震惊、灵光一闪、做成软件、以及接演示的情绪节点，加入「曼波～」「欧耶！」等语气词；由同一指定音色读出，不混入任何原角色音效。字幕与 LRC 包含这些实际发声词。

合成模型按官方文档使用 `moss-tts-2.0-flash-preview`，`language` 为 `Chinese`，并按官方语法插入 `[pause]`。片头约 3.5 秒无旁白，片尾在最后一句后留衔接空白，供「实用演示」标题落下。LRC 时间轴按成片音轨对齐；若后期重录，需按新录音微调。

## 成片口播（含语气词）

平时玩游戏，总想要个像样的方向盘，或者飞行摇杆。

有回我在购物网站上逛，越看越心动。再一看价格——真的方向盘、真的摇杆，动不动就大几百、上千。曼波～ 我盯着那个数字，手都缩回来了。

后来退而求其次，去闲鱼看看有没有二手，或者 DIY 的方案。确实便宜一些，可算下来还是小几百，而且还得自己折腾零件。犹豫了很久，还是没下手。

有天突然想到：我手上不是有一台 MatePad mini 吗？再加上 Gemini、ChatGPT、Grok Bot 这些 AI，写代码这事儿，好像也不是没办法。欧耶！

于是我就 vibe coding，一点点把现在这套软件做出来了。欧耶！它叫 HarmonyController。简单说，就是把鸿蒙平板或者手机，变成电脑这边的触控键盘、触摸板，还有游戏手柄。可以用 Wi-Fi，也可以用数据线，直接连到 Windows。

我最在意的，是按键能自由改。布局可以随便拖、随便缩放，横屏竖屏分开记。按键长什么样、绑哪个键、要不要组合键，都能自己定。不同游戏，就能排出完全不一样的操作面。

改好之后，还可以存成预设。预设市场里，能按游戏去下载别人的方案，也能把自己的布局发布出去，或者导出文件，分享给朋友。

至于实际上手好不好用——后面这一段，是我自己录的演示。曼波～
